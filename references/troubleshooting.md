# 现场 Bug 采样与排错规范

本文件用于 Pipeline 已经进入实机测试后发生失败时的处理。

## 1. 第一原则：先保留现场，再修

遇到失败时不要立刻：

```text
加 on_error
扩大 timeout
改固定坐标
增加新模板
```

先保留证据。

至少记录：

```text
失败节点
预期状态
实际状态
现场完整截图
OCR 原始结果
bbox / score
最近日志摘要
关键参数
当前 task_id / completed 等状态（若适用）
```

---

## 2. 本地图片如何交给远端模型

远端模型通常看不到执行 Agent 本地路径，例如：

```text
D:\project\debug\on_error\xxx.png
```

只发送路径是不够的。

若图片不含敏感信息，执行 Agent 应优先把图片本身注入当前聊天，并附简短上下文：

```text
失败节点：OpenShellOctopus
预期：点击左侧保留按钮
实际：OCR 超时
截图时间：19:37:34
```

然后附图。

已经验证可行的自动化方式包括：

```text
系统剪贴板 + 模拟真实 Ctrl+V
DataTransfer File 自动化挂载
```

发送后应等待远端模型确认图片可见，再继续视觉分析。

---

## 3. OCR 分框问题

不要只看“屏幕上人眼看到一句完整文字”。

必须看 OCR 的实际结果框。

例如：

```text
视觉按钮：保留一个随机奖品

OCR：
[保留]
[一个随机奖品]
```

若配置：

```text
expected = 保留一个随机奖品
```

可能完全无法命中，因为没有任何单一 OCR box 包含完整字符串。

优先修法：

```text
在目标 ROI 内选择
单个 OCR box 中稳定存在
且足够唯一的最小语义片段
```

例如：

```text
expected = 随机奖品
```

不要无意义缩短为太泛化的：

```text
奖品
继续
确定
```

除非 ROI 已经足够严格且不存在歧义。

---

## 4. 同一状态的多视觉布局

失败并不一定意味着出现了新业务状态。

先问：

```text
业务上是不是仍然应该做同一个动作？
```

例如结算页：

```text
变体1：只有“太好了”，按钮居中
变体2：“分享” + “太好了”，后者偏右
```

两者业务上都属于 Finish。

优先：

```text
记录 variant
→ 比较 bbox
→ 局部扩大统一 ROI
```

而不是立即增加两个 Finish 节点。

---

## 5. 局部校准原则

如果主状态机已经正确，而失败点只是：

```text
ROI 太窄
expected 太长
动画略慢
```

只修这一层。

不要因为一个识别 Bug 推翻已经跑通的整条状态机。

典型局部修正：

```text
expected 完整文案
→ 改成稳定语义片段

ROI 只覆盖居中布局
→ 扩展到两个实测 bbox
```

---

## 6. Timeout 问题

识别失败后超时，不代表 timeout 一定太短。

先确认：

```text
目标其实出现了吗？
OCR 有没有读出来？
读出来的文本是否被 expected 过滤掉？
ROI 是否覆盖？
```

只有确认“识别条件本身正确，只是页面确实更慢”以后，再调 timeout / delay。

禁止用超长 timeout 掩盖错误识别条件。

---

## 7. 固定坐标不是默认救火方案

如果 OCR 已经准确给出目标框，应优先点击识别结果。

固定坐标适合：

- 没有任何可靠识别结果；
- 页面布局高度固定；
- 经过实测确认；
- 且风险可控。

不要因为一次 OCR expected 写错就退化为硬编码坐标。

---

## 8. 测试次数策略

开发阶段优先：

```text
N=1
N=2
新任务重启 N=1
```

不要一上来设置 200 次，再用长跑来发现最基础的状态遗漏。

长时间 / 大次数运行属于后续稳定性验证。

---

## 9. 推荐失败报告模板

```text
## 失败节点
OpenShellOctopus

## 预期
识别左侧“保留一个随机奖品”并点击

## 实际
节点 20 秒超时

## OCR 原始结果
- 保留 | bbox=... | score=...
- 一个随机奖品 | bbox=... | score=...

## 当前配置
expected=保留一个随机奖品
roi=[...]

## 现场截图
<直接附图>

## 日志摘要
...
```

这种报告通常已经足够让高能力模型做局部诊断。
